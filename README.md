# Landing Page - Diagnóstico 360 (Grupo Galpão Hub)

## 📋 Sobre o Projeto

Landing page de alta conversão para o Diagnóstico 360 do Grupo Galpão Hub, uma consultoria estratégica que atua com empresários brasileiros no exterior.

## 🎨 Design System

### Paleta de Cores Oficial
- **Azul Escuro**: #063B5C
- **Azul Médio**: #377DA8  
- **Dourado**: #E3C161
- **Off White**: #FFFAF2
- **Marrom Escuro**: #3E392F

### Tipografia
- **Headers e Logo**: Ubuntu
- **Texto**: Helvetica

## 📁 Estrutura de Arquivos

```
/
├── index.html          # Estrutura principal da landing page
├── styles.css          # Estilos CSS com design responsivo
├── script.js           # JavaScript para interatividade e animações
├── README.md           # Documentação do projeto
└── assets/             # Pasta para imagens (criar quando necessário)
    ├── GG-LogoIcon.png
    ├── LOGO-recrie-1024x764.png
    ├── LOGO-OFFRio-1024x764.png
    └── LOGO-SoHigh-1024x764.png
```

## 🚀 Como Usar

1. **Adicionar as imagens**: Coloque os arquivos de logo na pasta `assets/`:
   - `GG-LogoIcon.png` - Logo do Grupo Galpão
   - `LOGO-recrie-1024x764.png` - Logo da Re.crie
   - `LOGO-OFFRio-1024x764.png` - Logo da OFFRio
   - `LOGO-SoHigh-1024x764.png` - Logo da SoHigh

2. **Abrir a página**: Abra o arquivo `index.html` em qualquer navegador moderno

3. **Personalizar**: Edite os textos e métricas conforme necessário

## ✨ Funcionalidades

### Seções da Landing Page
- **Header**: Logo + CTA fixo
- **Hero**: Promessa principal + prova social
- **Como Funciona**: 4 etapas do diagnóstico
- **Benefícios**: 4 benefícios imediatos
- **Diferenciação**: Por que escolher o Grupo Galpão
- **Casos de Sucesso**: 3 cases com métricas reais
- **Formulário**: 6 perguntas estratégicas + dados de contato
- **FAQ**: 4 perguntas frequentes
- **Call Final**: Urgência + CTA
- **Footer**: Links institucionais

### Interatividade
- Animações de entrada suaves
- Efeito parallax no hero
- Contadores animados para métricas
- Smooth scroll para navegação
- Validação de formulário
- Efeitos hover nos botões
- Header que se esconde ao rolar para baixo

### Responsividade
- Design mobile-first
- Breakpoints: 768px e 480px
- Grid responsivo para todas as seções
- Formulário otimizado para mobile

## 🔧 Personalização

### Alterar Cores
Edite as variáveis CSS no arquivo `styles.css`:
```css
:root {
    --azul-escuro: #063B5C;
    --azul-medio: #377DA8;
    --dourado: #E3C161;
    --off-white: #FFFAF2;
    --marrom-escuro: #3E392F;
}
```

### Alterar Textos
Edite diretamente no arquivo `index.html` nas respectivas seções.

### Adicionar Novos Cases
Copie a estrutura de um case existente e adicione na seção `.success-cases`.
